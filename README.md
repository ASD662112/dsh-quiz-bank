# 数字媒体专业(3+2)转段考试题库（网页版）

数字媒体专业 3+2 转段考试练习题库，单文件离线 HTML，双击即用、无需联网。

## 题库

- **三科题库**：PS 平面设计（225 题）、二维动画制作（206 题）、平面设计师与计算机网络安全（180 题）
- **二科目+一证书练习题库**：同上内容，练习入口略有差异

## 功能

- 单选 / 多选 / 判断 / 填空 / 简答 五种题型，客观题自动判分，填空简答按关键词判分
- 顺序练习、模拟考试（限时计时+时间条）、错题重练
- 学习统计面板（正确率、各题型、最近 12 次趋势）
- 收藏重点题、搜索跳题、背诵模式、错题本管理页
- 夜间模式、字号调节、快捷键（按 ? 查看）
- 模拟考试结果页一键导出 PNG / HTML / PDF

## 使用

直接双击 HTML 文件用浏览器打开即可。进度、错题、收藏均保存在本机浏览器 localStorage。
